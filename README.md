# WoodMarket — MVP

Учебный интернет-магазин деревянных изделий. Основа главной страницы и изображения сохранены из исходного архива.

## Стек
- HTML, CSS, JavaScript (без сборщика и фреймворка)
- Python, FastAPI
- Данные товаров: локальный JSON; база данных не используется

## Локальный запуск

Требуется Python 3.10+.

```bash
cd woodmarket-main
python -m venv .venv
# Windows: .venv\Scripts\activate
pip install -r backend/requirements.txt
uvicorn backend.app.main:app --reload
```

Откройте **http://127.0.0.1:8000/**. Документация API: **http://127.0.0.1:8000/docs**. (не httpS, а http!)

## Основной сценарий
Главная → Каталог (поиск, категория, материал, цена, сортировка) → Карточка товара → Расчёт по размерам и материалу → Заявка → Демонстрационное подтверждение.

Избранное сохраняется в localStorage. Заявки не сохраняются и никуда не отправляются: FastAPI проверяет данные и возвращает демонстрационное подтверждение. Авторизация, оплата, внешние интеграции и кабинет продавца не предусмотрены.

## Примечания
- Каталог и изображения демонстрационные; для некоторых товаров используются фотографии из исходного архива повторно.
- Формула расчёта условная: базовая цена × отношение объёмов × коэффициент материала; результат округляется до 100 ₽.
- Для формы заявки обязательны имя, телефон и email. На сервере проверяется корректность телефона и email.
- Запускать сайт нужно через FastAPI, а не двойным кликом по HTML-файлу: иначе API недоступен.
- Это демонстрационная версия: после отправки формы контактные данные не сохраняются, не отправляются по почте и не передаются продавцу.
